# 0.7 开局向导（Onboarding）

> 状态：待用户确认
> 关联文档：[02 人物构建层](./02-character-layer.md) · [04 人生模型](./04-life-model.md) · [05 全随机模式](./05-roulette-mode.md)

---

## 1. 定位

开局向导是「玩家按下开始」到「引擎接管这段人生」之间的全部步骤。它要解决三件事：

1. **交代清楚这一局的前提**：进哪个世界、用哪套属性、这段人生是完整一生还是片段连载
2. **让人物诞生**：抽取（或选购）特质 → 合成六维 → 生成人物卡
3. **把不适内容的选择权交给玩家**：内容偏好面板（默认全关，见 02 文档第 10 节）

设计原则：**默认即安全、默认即完整** —— 不调任何设置直接点「开始」，也能得到一段体验完整的人生。

---

## 2. 流程总览

```
选世界 → 选属性系统 → 内容偏好 → 人物构建 → （重抽）→ 人物卡确认 → 名字/性别 → 进入人生
  1         2            3           4          5           6            7
```

| 步 | 界面 | 产出 |
|---|---|---|
| 1 | 世界选择 | `worldId`、`WorldMeta`（含 `lifeModel` / `recommendedStyles`） |
| 2 | 属性系统选择 | `AttrSystemId`：`classic5` / `heart6` / `roulette` |
| 3 | 内容偏好 | `ContentPrefs`（默认空 = 全关） |
| 4 | 人物构建 | 转盘抽卡（`roulette`）或 roll + 点数（另两套） |
| 5 | 重抽 | 副线池最多 1 次（`roulette` 专属） |
| 6 | 人物卡确认 | `CharacterCard`（特质 / 六维 / 心理状态量基线） |
| 7 | 名字与性别 | `name`、`gender` 最终值 |

---

## 3. 各步细则

### 3.1 选世界

- 卡片列表：世界名 + 一句话简介 + `lifeModel` 标注（「完整一生」/「片段连载」）+ 推荐风格缩略
- 选择后展示 `opening`（开局独白），作为世界观交代
- **这一步只用已写完事件库的世界**，未完成的世界置灰或不下发（P0 只放赛博朋克）

### 3.2 选属性系统

| 系统 | 展示文案方向 | 人物构建方式 |
|---|---|---|
| 经典五维 `classic5` | 直观易懂，第一次玩选这个 | 特质池 roll + 预算点数（待确认，见第 7 节） |
| 心之禀赋 `heart6` | 只看内在，跑团检定手感 | 同上 |
| 全随机 `roulette` | 把命运交给转盘 | **转盘抽卡**（见 3.4） |

### 3.3 内容偏好（显眼位置，不藏二级菜单）

- 位置：属性系统选择之后、人物构建之前 —— 玩家在抽之前先表明能接受什么
- 顶部一句话：**「以下内容默认关闭。想让这段人生更有戏剧性，可以按类别或逐条打开。」**
- 交互两级粒度：
  - **类别整组开关**（9 类：外貌 / 感官 / 肢体 / 内脏慢病 / 神经 / 心理病理 / 成瘾 / 家庭处境 / 族裔教育）
  - **单条勾选**（例：只开「肥胖」「丑陋」，不开「残疾」「成瘾」）
- 数据侧：面板用 `groupByCategory(pool)` 一次取全分组，结果写入 `ContentPrefs { sensitive?, tender? }`
- 结果存本地偏好，下次开局默认沿用
- **设置页也要有同一个面板**（2026-09-24 补充）：分类下拉 + 每类「全开 / 全关」+ 逐条勾选，与开局向导共用同一份本地偏好 —— 玩家中途想改不必重新开局
- 数据侧已就绪（2026-09-24）：235 + 24 条特质全部带 `safety.tender` / `safety.category`，9 类分组可直接列出

### 3.4 人物构建

**`roulette` 模式（转盘）**

- 按 05 文档的顺序：主线槽逐个定格 → 副线池逐个掷「是否抽中」
- 每个槽位定格后短暂停留展示标签（约 0.6s，可长按跳过）
- 副线池掷中但候选为空 → 直接显示「无」（默认设置下的常见结果，见 02 文档 10.4）
- 抽完做互斥检查（同组只留一个）

**`classic5` / `heart6` 模式**

- 开局方式待确认（见第 7 节待确认项 1）：倾向「特质池 roll + 有限点数置换」，`RARITY_COST` 与 `budgetCap = 8` 已为此预留

### 3.5 重抽

- 仅 `roulette` 模式有；**每局限 1 次，且只能重抽副线池的槽位**
- 入口放在人物卡上（「有一个槽位不满意？改写一次运气」）
- 主线槽不可重抽 —— 主线抽的是「命」，副线抽的是「运」

### 3.6 人物卡确认

一屏之内看完这一局的前提：

| 区块 | 内容 |
|---|---|
| 基本形象 | 性别 / 年龄起点 / 身高 / 体型 / 发色 / 瞳色等（`visual` 字段） |
| 特质清单 | 按路径分组（先天 / 后天 / 状态），展示名优先用 `neutralLabel` 现象化文案 |
| 六维 | 条状图（`roulette` 下就用六维；另两套用各自属性） |
| 心理状态量 | 韧性 / 信任 / 自我价值 / 压抑度，四项均可后置隐藏，按需展示 |
| 提示词预览 | 二期做立绘时直接从这里拼（P0 可隐藏） |

- 底部两个按钮：**「开始这段人生」** / **「重抽副线（剩 1 次）」**

### 3.7 名字与性别

- 名字：**默认随机生成一个**（按世界语感给名库），可点击修改；不强制玩家输入
- 性别：`roulette` 模式下由转盘决定；`classic5` / `heart6` 模式下是否自选见第 7 节待确认项 3

## 4. 交互细节

| 项 | 方案 |
|---|---|
| 快速模式 | 设置项。开启后跳过逐个定格动画，直接出人物卡 |
| 长按跳过 | 长按任意处立即结束当前动画（05 文档已约定） |
| 返回上一步 | 保留已抽结果，避免玩家误触后重抽（重抽是有限资源） |
| 中断续接 | 未完成开局向导就退出 → 不落存档，下次重新开始（开局不是「局内」） |

## 5. 产出：RunState 初始值

向导结束时一次性写入（字段定义见 [03 文档](./03-runstate-save.md)）：

```ts
{
  worldId, attrSystem, lifeModel,
  age, chapter,                    // full: age=0；episodic: age=startAge
  attrs,                           // 合成后的属性
  card,                            // CharacterCard（特质 / 形象 / 提示词）
  psyche,                          // 心理状态量基线（叠加特质修正）
  relations: [],                   // 开局为空，人生中逐渐建立
  tags, caps, money,               // 由特质 / 背景包注入
  history: [], status: 'running',
}
```

## 7. 待确认项

1. **`classic5` / `heart6` 模式的开局方式**：是「也走特质池，但把转盘换成一次性列表」还是「属性 roll（`init` 区间随机）+ 有限点数置换特质」？（`RARITY_COST` / `budgetCap` 已为点数方案预留）
2. **名字**：默认随机即可，还是要求玩家必填？
3. **性别**：`classic5` / `heart6` 模式下是否让玩家自选？
4. **内容偏好面板是否在设置页也放一份**（作为全局默认，向导里可临时覆盖）
5. **人物卡是否显示心理状态量四项**（P0 建议隐藏，避免开局信息过载）
6. **是否显示提示词预览区**（P0 建议隐藏，二期做立绘时再露出）
