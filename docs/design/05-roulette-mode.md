## 1. 定位

**转盘 = 全随机模式 = 六维系统 + 人物全随机。**

它不创造新的属性名，输出仍然是六维（洞见 / 持守 / 通感 / 机变 / 遐思 / 行力）。区别只在**开局如何得到数值**：

| 属性系统 | 开局方式 |
|---|---|
| `classic5` 经典五维 | 玩家分配 / 随机 roll |
| `heart6` 心之禀赋 | 玩家分配 / 随机 roll |
| `roulette` 全随机 | **转盘抽特质 → 特质直接定义六维 + 心理状态量** |

因此 `ROULETTE` 直接复用 `HEART6` 的属性定义与映射，**差异只在开局生成流程 + 人物卡**。

```ts
export const ROULETTE: AttrSystem = {
  id: 'roulette',
  name: '全随机',
  brief: '你无法选择自己是谁。转盘决定你的身体、出身与心性，也决定你的六维。',
  attrs: HEART6.attrs,   // 复用六维定义
  hidden: HEART6.hidden, // 复用「命途」
  map: HEART6.map,       // 复用语义键映射
};
```

## 2. 转盘结构：主线槽 + 副线池

内容量扩充到上百条后**不能平铺成 20+ 个槽位**（动画会冗长到毁掉节奏）。方案：

### 主线槽（10 个，逐个定格，必抽）

| 顺序 | 槽位 | 候选来源 | 可视化出口 |
|---|---|---|---|
| 1 | 性别 `gender` | 通用池 | 文字 |
| 2 | 身高 `height` | 通用池 | 数值 + 总结图 |
| 3 | 体型 `build` | 通用池 | 文字 + 总结图轮廓 |
| 4 | 发色 `hair` | 通用池 | **色块** |
| 5 | 瞳色 `eye` | 通用池（含异瞳） | **色块（异瞳双色）** |
| 6 | 视力 `vision` | 通用池 | 符号（`eye-off`） |
| 7 | 容貌 `looks` | 通用池 | 文字 |
| 8 | 性格 `personality` | 通用池 | 文字 + 标签 |
| 9 | 道德 `morality` | 通用池 | 文字 |
| 10 | 出身 `origin` | 世界背景包 | 文字 |

> `startAge` 槽位仅在 `episodic` 世界追加。

### 副线池（命运牌，概率抽）

每个池**先掷「是否抽中」**，中了才翻一张「命运牌」：

| 池 | 槽位 | 建议抽中概率 | 内容 |
|---|---|---|---|
| 生理·形态 | `bodyForm` | 40% | 面部 / 毛发 / 皮肤 / 年龄感 |
| 生理·机能 | `bodyFunc` | 30% | 听力 / 言语 / 肢体 / 慢性病 / 神经 |
| 心理·人格 | `psyche` | 45% | 大五人格 / 气质 / 意志 / 社交 |
| 心理·病理 | `psycheClinic` | 20% | 情绪 / 焦虑 / 创伤 / 成瘾（敏感池） |
| 天赋才能 | `aptitude` | 35% | 艺术 / 数理 / 语言 / 运动 |
| 社会细项 | `social` | 30% | 家庭结构 / 族裔 / 教育 / 信仰 |

**「抽不中」本身就是「无」的表达**——多数人没有残疾、没有病理，这就是真实感。因此池内**不需要列 `none` 条目**（会占预算、污染数据）。

> 收益：内容量翻 3 倍，转盘动画时长不变。

## 3. 获取路径与人生模型的关系

特质的三条获取路径（`innate` / `acquired` / `state`，详见 02 文档第 2 节）决定了**各池在不同人生模型下的开局可用性**：

| lifeModel | 可进开局池的路径 | 说明 |
|---|---|---|
| `full` 生到死 | 仅 `innate` | 心理病理（`acquired`）**不入开局池**，只能由人生事件后天触发 |
| `episodic` 片段连载 | `innate` + `acquired` | 先天与后天都可开局存在，这正是「这个人有故事」的切入点 |

**失明示例**（用户规则）：

```
full 模式：抽到「先天失明」→ 先天失明；没抽到 → 后续可能因事故后天失明
episodic ：「先天失明」与「后天失明」都可能开局抽到
```

**心理病理示例**：

```
full 模式：幼年不可能有「酗酒」「抑郁」
          开局只可能有「易感体质」类（神经质偏高、敏感气质）
          临床病理靠 suppression 累积过阈值后天触发
episodic ：可开局携带临床病理（抑郁 / PTSD / 成瘾）
```

实现：`TraitUnlock.models` + `TraitUnlock.acquiredOnly` 过滤。

## 4. 抽取流程

```
1. 生成 seed（或由玩家重开次数派生）
2. 前置过滤（统一走 data/traits/index.ts 的 canEnterOpeningPool()，抽卡实现不重复判断）：
     按 lifeModel 过滤 paths（full 只留 innate）
     按 unlock 过滤（models / minAge / requiresSuppression）
     按内容偏好过滤：safety.sensitive 与 safety.tender **默认都不入池**，
       只有玩家在开局向导「内容偏好」面板里勾选过的 id 才放行
3. 主线槽逐个抽取：
     候选 = 池中该槽位的全部特质
     权重 = traitWeight(候选)，即 (weight ?? RARITY_WEIGHT[rarity]) × 内容系数
            内容系数：sensitive 0.3 / tender 0.5 / 其余 1
     加权随机取 picks 个（默认 1）
4. 副线池逐个掷「是否抽中」：
     掷中（概率 poolChance）→ 在该池内加权随机取 1 条；
       若池内候选为空（默认设置下 psycheClinic、bodyFunc 即如此）→ 同样判定为「无」
     未掷中 → 该池为空（即「无」）
5. 互斥检查：
     同一互斥组内只保留一个（见 02 文档第 5 节）
6. 展开 traits → 合成六维（02 文档第 6 节）
7. 初始化心理状态量：psyche = { ...pool.psycheBaseline }（叠加特质修正）
8. 生成 CharacterCard（含 summaryText 与 visual / promptTags 信息）
```

### 稀有度默认权重与预算

| 稀有度 | 抽取权重 | 预算成本 | 定位 |
|---|---|---|---|
| `common` | 8 | 1 | 常态特质 |
| `rare` | 4 | 2 | 明显优势 |
| `epic` | 1.5 | 3 | 极端优势，伴随代价 |
| `curse` | 2 | -1 | 纯负面，但有节目效果（如「先天失明」→ 洞见 +4 / 行力 -3） |

**负面/敏感特质的概率压制**：`safety.sensitive = true` 的特质，权重再乘 **0.3** 安全系数。

| 特质 | 稀有度 | 基础权重 | 实际权重 |
|---|---|---|---|
| 失眠、轻度焦虑 | `common` | 8 | 2.4 |
| 单耳失聪、慢性病 | `rare` | 4 | 1.2 |
| 人格障碍、重度成瘾 | `curse` | 2 | 0.6 |

→ **现实中少见的重度负面特质自然成为「命运」，无需逐条手工调参**（详见 02 文档第 11 节）。

## 5. 心理状态量的开局初始化

| lifeModel | 开局心理状态 |
|---|---|
| `full` | 从 `psycheBaseline` 起步（建议每项 10），随人生事件增减 |
| `episodic` | `psycheBaseline` + 所抽特质/病理的修正（如开局携带 PTSD → `suppression` 初始即高于基线） |

状态量含义与病理触发规则见 [02-character-layer.md](./02-character-layer.md) 第 4 节。

**关键**：心理状态量在 `full` 模式下**不抽取**，它是「环境反馈 + 经历事件」累积出来的——这才是全随机模式里「活得成什么样」而非「出生是什么样」的部分。

## 6. 转盘动画节奏（UI 约定）

| 阶段 | 时长 | 表现 |
|---|---|---|
| 起转 | 0.4s | 轮盘加速，模糊 |
| 主线槽定格 | 0.8s × 10 | 逐槽停止，高亮结果 |
| 结果卡片浮入 | 0.3s | 特质名 + 描述 + 六维偏移预览 |
| **命运牌翻面** | 0.5s × N | 副线池抽中时翻牌；未抽中显示「未抽中」牌背 |
| 全部抽完 | — | 人物卡总览 + 六维推导动画（偏移逐条累加） |

> 动画为纯表现层，不影响数据。支持「跳过动画」（长按）。

---

## 7. 与检定、时间漂移的关系

| 项 | 规则 |
|---|---|
| 检定 | 完全沿用 `1d20 + floor(六维/2) ≥ DC`，与另两套系统共用难度档 |
| 时间漂移 | **默认开启**（`full` 模型下人生仍在流动），规则与六维系统完全一致 |
| 与特质的关系 | 漂移作用在六维数值上；特质偏移是开局一次性注入，不随时间衰减 |
| `episodic` 世界 | 按世界声明的 `timeDrift` 决定是否开启 |

## 8. 平衡保障

全随机最大的风险是「废人开局」与「超人开局」。四道闸门：

1. **预算上限**：`Σ cost ≤ budgetCap`，超了重抽最贵的非必需特质
2. **区间 clamp**：六维限制在 `[0, 20]`
3. **互斥检查**：防止同一特征双重叠加
4. **模拟验证**：第 3 步批量模拟（数百次）输出六维分布直方图，若出现明显双峰或极端离群，回调池的偏移数值
